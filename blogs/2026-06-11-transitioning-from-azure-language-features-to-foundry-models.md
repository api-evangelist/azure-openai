Azure AI Language in Foundry Tools will begin deprecating eight features: Key Phrase Extraction, Entity Linking, Sentiment Analysis & Opinion Mining, Summarization (document & conversation), Conversational Language Understanding (CLU), Custom Question Answering (CQA), Orchestration Workflow, and Custom Text Classification, to be ultimately retired by March 2029 (Entity Linking even sooner, by September 20, 2028 ). Microsoft’s guidance is to implement these functionalities using Microsoft Foundry-based models. This series of recommendation guides is intended to help you get started as you explore the breadth of Foundry-based options at your fingertips.
