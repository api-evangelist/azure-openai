What if your support team could start every morning with an AI-generated summary of tickets most likely to breach SLA? This tutorial shows you how to build exactly that: a grounded agent in Microsoft Foundry that automatically analyzes your ticket data and surfaces risks. Using Routines in Microsoft Foundry, we run the agent on a recurring schedule so risks are identified early and addressed before they escalate.
