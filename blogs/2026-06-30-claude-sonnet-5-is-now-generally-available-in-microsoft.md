On June 29, 2026, we announced the general availability of Claude in Microsoft Foundry , giving enterprises a production-ready path to build with Claude models in the Azure ecosystem. Today, we’re continuing that momentum with the general availability of Claude Sonnet 5 in Microsoft Foundry. Claude Sonnet 5 brings Anthropic’s most capable Sonnet model to Microsoft Foundry, where developers can use it with Foundry Agent Service and Microsoft IQ to build, ground, evaluate, and scale Agentic applications.
