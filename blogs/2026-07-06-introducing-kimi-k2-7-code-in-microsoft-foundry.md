Modern software engineering rarely happens in a single step, developers must refactor across large codebases, implement features spanning multiple files, and debug issues over long-running sessions. Kimi K2.7 Code from Moonshot AI, available on Microsoft Foundry starting July 1, 2026 in public preview, is designed to tackle these challenges. Building on the K2.6 series, it delivers meaningful advances in end-to-end task success, reasoning efficiency, and developer productivity scenarios , making it a more effective tool for real-world, long-horizon coding workflows.
